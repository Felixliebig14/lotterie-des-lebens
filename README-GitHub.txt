HOCHLADEN
1. ZIP entpacken (nicht die ZIP-Datei selbst hochladen).
2. Repository felixliebig14/lotterie-des-lebens öffnen.
3. Auf 'uploading an existing file' klicken.
4. Alle Dateien aus dem entpackten Ordner auswählen.
5. 'Commit changes' klicken.
6. Settings > Pages > Deploy from a branch > main > /(root) > Save.
7. Nach Veröffentlichung z. B. Los 00001, 00025, 00050 und QR-Codes testen.

Falls zuvor die alten Dateien los-11111.html bis los-11160.html hochgeladen
wurden, diese alten Dateien im Repository entfernen, um Verwirrung zu vermeiden.

Die 50 Texte sind eine rekonstruierte Fassung der ursprünglichen Losliste.
Vor der Druckfreigabe bitte den Inhalt redaktionell überprüfen.
